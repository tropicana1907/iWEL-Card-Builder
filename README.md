# iWEL Card Builder 2.0

Конструктор коммерческих предложений iWEL: карточки квартир 1080×1920 с расчётом рассрочки, планировкой, генпланом и видами из окон. Работает полностью в браузере, без сервера — данные (библиотека квартир, планировки, генпланы) хранятся в localStorage.

**Живая версия:** https://tropicana1907.github.io/iWEL-Card-Builder/

**Встраивание на iwel.ru/card (Tilda):** готовый сниппет и инструкция — [docs/tilda-embed.html](docs/tilda-embed.html). Хостинг остаётся на GitHub Pages, обновления при пуше в `main` подхватываются на iwel.ru/card автоматически.

## Возможности

- **Конструктор КП** — форма слева, живое превью карточки справа; экспорт в PNG / JPG / PDF / WhatsApp-сжатый JPG / буфер обмена
- **Быстрый расчёт** — несколько вариантов рядом (прямой расчёт «взнос → платёж» и обратный «платёж → нужный взнос»), из любого варианта создаётся КП в один клик
- **Генплан с лучами видов** — точка квартиры ставится кликом или пальцем (тач-поддержка), лучи Запад/Север/Восток/Юг с настраиваемой шириной и прозрачностью, компас на карточке
- **Шаблоны проектов** — Империал, Башни, свой; у каждого свои адрес, компас, преимущества, высота потолков
- **Библиотека квартир и планировок** — сохранение и повторное использование

## Что нового в 2.0

- Фирменная типографика (Playfair Display + Manrope, кириллица, самохостинг — корректно попадают в PNG/PDF-экспорт)
- Исправлена геометрия точки на генплане: редактор и карточка теперь используют одну пропорцию 2.7:1 — точка больше не «уезжает» на экспорте
- Редактор генплана учитывает выбранную ориентацию компаса (превью = карточка)
- Редактор генплана работает на телефонах (pointer events вместо mouse-only)
- Финансовые блоки больше не переполняют карточку (flex-раскладка вместо px-математики)
- Шаблон «Башни» без введённой цены больше не показывает цены Империала
- Модалка редактора больше не «застревает» открытой после перезагрузки страницы
- Переполнение localStorage теперь сообщается пользователю, а не глотается молча
- Компас-роза на генплане карточки, номер квартиры в инфо-строке
- Удалён мёртвый код (ParametersPanel, неиспользуемые константы)

## Разработка

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # статический экспорт в ./out
```

Деплой — автоматически на GitHub Pages при пуше в `main` (см. `.github/workflows/deploy.yml`).

## Размещение в iwel-presentations (/card)

Конструктор также размещён в репозитории страниц проектов [likeahustla/iwel-presentations](https://github.com/likeahustla/iwel-presentations) по пути `/card`:
**https://likeahustla.github.io/iwel-presentations/card/**

Обновление после изменений в этом репозитории:

```bash
BASE_PATH=/iwel-presentations/card npm run build
# скопировать содержимое out/ в папку card/ репозитория iwel-presentations и запушить
```

В корне iwel-presentations лежит `.nojekyll` — без него GitHub Pages выбрасывает папку `_next/` со скриптами и шрифтами.
